Tracing the Activity Selection

Context The Problem Statement

Given n activities with their start and finish times.
Select the maximum number of activities that can be performed by a single person, assuming, that a person can only work on a single activity at a time.

Example:
Step 1 / 2
Activity A1 A2 A3
Start 12 10 20
Finish 25 20 30
Total activities performed: A2, A3: 2 activities
• A2 runs from 10 to 20 (finish = 20)
• A3 starts at 20 (compatible: 20 ≥ 20) and finishes at 30
• A1 runs from 12 to 25, creating a collision with both A2 and A3!
Method Solution; Greedy Approach
1
SORT all activities by finish time

Order activities in non-decreasing (ascending) order of their finish times.

2
SELECT the first activity, set last_finish to its finish time.
3
GO DOWN THE LIST: ask: is start ≥ last_finish?

• Yes: select it, and update last_finish to its finish time
• No: skip it, last_finish stays the same

4
Stop at the end of the list and the selected activities are the answer.
Note: If the start time of the activity is greater than or equal to the finish time of previously selected activity, then select this activity and print it.

def print_max_activities(s, f, n):
    # s[] = start times,
    # f[] = finish times (already sorted by finish time)
    print("Following activities are selected")

    # The first activity always gets selected
    i = 0
    print(i, end=" ")

    # Consider the rest of the activities
    for j in range(1, n):
        # If this activity starts at or after the last selected one finishes, select it
        if s[j] >= f[i]:
            print(j, end=" ")
            i = j

Proof Evidence / Proof: Greedy Stays Ahead
Establishing why the Greedy algorithm is mathematically guaranteed to be optimal.
The Core Invariant

"The k-th activity picked by the greedy algorithm finishes no later than the k-th activity in any other valid schedule."

We need to show two things:

1 The Lemma

This statement is true: greedy is never behind any valid schedule at any position.

2 The Theorem

If it's true, the greedy algorithm must be optimal (no schedule can contain more activities).

Evidence / Proof: Greedy Stays Ahead
Notation definitions used across the induction and contradiction proofs.
S

The schedule produced by the greedy algorithm.

S*

An optimal (best possible) schedule.

|S| and |S*|

The number of activities in S. Likewise, |S*| is the number in S*.

f(i, S)

The finish time of the i-th activity in schedule S.

U

The set of activities still available to pick, meaning those that don't overlap anything already chosen.

Since S* is the best possible, |S| ≤ |S*|. We still need to show |S| ≥ |S*|.
Lemma: greedy is never behind
Proof by induction that greedy's picks finish no later than optimal picks.
Claim: For every position 1 ≤ i ≤ |S|, f(i, S) ≤ f(i, S*)

The i-th activity of greedy finishes no later than the i-th activity of the optimal schedule.

Base case (i = 1):

Greedy's first pick is the activity that finishes earliest of all, so it can't finish later than the first activity of S*.
Therefore: f(1, S) ≤ f(1, S*).

Inductive step:
• Assume the claim is true for some position i < |S|, so greedy's i-th activity ends no later than S*'s i-th activity.
• S*'s (i+1)-th activity starts at or after S*'s i-th activity ends.
• That means it also starts at or after greedy's i-th activity ends.
• So S*'s (i+1)-th activity is still in U when greedy makes its (i+1)-th pick.
• Greedy picks the activity in U that finishes earliest, so f(i+1, S) ≤ f(i+1, S*). ■
Theorem: greedy is optimal
Proof by contradiction that greedy produces an optimal schedule.
Claim: The greedy algorithm produces an optimal schedule (|S| = |S*|)
Proof (by contradiction):
1. We already know |S| ≤ |S*|. We need to prove |S| ≥ |S*|.
2. Suppose instead that |S| < |S*|, and let k = |S|.
3. By the Lemma, f(k, S) ≤ f(k, S*).
4. Since S* has more than k activities, it has a (k+1)-th activity.
5. That activity starts at or after f(k, S*), and so at or after f(k, S).
6. So, after greedy picked its k-th activity, the (k+1)-th activity of S* was still in U.
7. But greedy stopped after k activities, which only happens when U is empty.

This is a contradiction! So the assumption was wrong. Therefore |S| ≥ |S*|, and greedy is optimal. ■
