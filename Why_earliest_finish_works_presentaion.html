Why Earliest Finish Works

Understand the Activity Selection Problem, see the Python code, and learn why choosing the activity that finishes first leads to an optimal result.

1. Context

The Earliest Finish algorithm is a greedy algorithm that selects the maximum number of non-overlapping activities. Each activity has a start time and a finish time.

  1. Sort activities by finish time, from earliest to latest.
  2. Select the first activity.
  3. Choose the next activity only if its start time is at or after the last selected activity's finish time.
  4. Continue until all activities have been checked.

2. Algorithmic Response (Coding)

This Python program sorts activities by finish time, selects compatible activities, and prints the result.

Python implementation

def activity_selection(activities):
    # Sort activities by finish time
    activities.sort(key=lambda activity: activity[1])

    selected = []
    last_finish = 0

    for start, finish in activities:
        if start >= last_finish:
            selected.append((start, finish))
            last_finish = finish

    return selected


activities = [(1, 3), (2, 5), (3, 4), (4, 6), (6, 8)]

result = activity_selection(activities)

print("Selected activities:", result)
print("Total activities:", len(result))

3. Evidence / Proof

The algorithm is correct because of the greedy-choice property and optimal substructure.

  1. Greedy choice: Let A be an activity with the earliest finish time. Choosing A leaves at least as much time for later activities as choosing any activity that finishes later.
  2. Exchange argument: If an optimal schedule starts with another activity B, replace B with A. Since A finishes no later than B, all activities after B remain compatible. The number of selected activities does not decrease.
  3. Optimal substructure: After choosing A, the remaining task is the same problem restricted to activities that start at or after A finishes.
  4. Repeat: Applying the same reasoning to the remaining activities shows that every greedy choice can be part of an optimal schedule. Therefore, the algorithm selects the maximum possible number of compatible activities.

Conclusion

Earliest Finish works because choosing the activity that ends first preserves the most time for the remaining activities. The exchange argument proves that this choice does not reduce the best possible answer.
