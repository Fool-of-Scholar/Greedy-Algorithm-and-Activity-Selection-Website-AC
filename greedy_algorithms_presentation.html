When Greedy Algorithms Fail

Algorithms & Complexity

Context & Definition

A greedy algorithm makes the locally optimal choice at each stage with the hope of finding a global optimum. However, this approach fails when a problem's local decisions permanently lock you out of the best overall solution.

Requirements for Success:

  • Greedy-Choice Property: A global optimum can be arrived at by selecting a local optimum.
  • Optimal Substructure: An optimal solution to the problem contains optimal solutions to subproblems.

When these are absent, the algorithm acts "short-sightedly".

Evidence 1: The Coin Change Problem

Goal: Make change for a specific amount using the fewest number of coins.

The Setup

  • Available Coins: 1, 3, 4
  • Target Amount: 6

Greedy Approach (Fails)

Pick the largest coin first.

4 → 1 → 1
(Total: 3 coins)

The Optimal Solution

The true optimal solution is to ignore the locally best '4' and select two '3's.

3 → 3 (Total: 2 coins)

Evidence 2: 0/1 Knapsack Problem

Goal: Maximize total value in a backpack without exceeding weight capacity.

Setup (Max Weight: 50kg)

ItemWeightValueRatio
A10 kg$60$6/kg
B20 kg$100$5/kg
C30 kg$120$4/kg

Greedy (Sort by Ratio)

Takes A (10kg) → B (20kg). Can't fit C.

Weight: 30kg | Value: $160

Optimal Solution

Ignore best ratio (A), pack B + C.

Weight: 50kg | Value: $220

Conclusion

Greedy algorithms are fast and memory-efficient (often $O(n \log n)$), but they are dangerous if applied blindly.

The Takeaway:

They fail when current optimal choices conflict with future optimal combinations. To guarantee correct results in these scenarios, exhaustive methods like Dynamic Programming are required to evaluate overlapping subproblems.
